Getting Started with Potemkin

Potemkin ships as a zero-dependency Python 3.10+ CLI, an Agent Skill (npx skills add / Claude Code plugin), a composite GitHub Action (codesphere-u/potemkin@v1), and a Docker image.

Agent Skill & CLI

v1.1.0 
npx skills add codesphere-u/potemkin
uvx --from git+https://github.com/codesphere-u/potemkin potemkin . --diff HEAD
pip install git+https://github.com/codesphere-u/potemkin.git

First Scan

Run Potemkin against your repository root with git diff inspection enabled so both runtime code and recent test edits are verified together.

potemkin . --diff HEAD --fail-on high --min-score 90

6 Pillars & Integrity Scoring

Potemkin groups 16 checks (POT001–POT016) into 6 architectural integrity pillars. Browse every rule interactively in the Rules Matrix.

Severity Weights

SeverityDeductionGrade Thresholds
CRITICAL-18 pts each90–100 = VERIFIED
HIGH-9 pts each70–89 = CAUTION
MEDIUM-4 pts each< 70 = POTEMKIN ALERT
LOW-1 pt eachScore floors at 0

Recommended Triage Priority

  • Security first: POT011 (hardcoded secret fallback), POT012 (secret exposed with public prefix), POT006 (unverified webhook).
  • Deceptive stability next: POT004 (fake fallback success) and POT014–POT016 (diff-time skipped tests or suppressions).
  • Completion & wiring: POT001–POT003 (hollow UI), POT007 (mock fixtures), and POT008–POT010 (route mismatches & localhost URLs).

GitHub Action & SARIF 2.1.0

Use codesphere-u/potemkin@v1 in GitHub Actions to enforce score thresholds and upload SARIF alerts into GitHub Code Scanning.

PR Gate Workflow

- name: Potemkin Real-Code Gate
  uses: codesphere-u/potemkin@v1
  with:
    path: "."
    diff: "origin/main"
    fail-on: "high"
    min-score: "90"
    sarif-file: "potemkin.sarif"

Action Outputs

The composite action exports score (0–100), grade (VERIFIED, CAUTION, or POTEMKIN ALERT), critical-count, and sarif-file.

Baselines & Suppression Directives

Adopt Potemkin on existing repositories without rewriting legacy code in a single PR.

Baseline Ratchet

potemkin . --write-baseline .potemkin-baseline.json
potemkin . --baseline .potemkin-baseline.json --fail-on high

.potemkin.json & Inline Ignores

Configure ignored rules, paths, or inline overrides with explicit justification: // potemkin-ignore: POT010 - local mock server in Storybook. Use .potemkinignore with glob patterns for generated vendor directories.

Architecture & Self-Audit

Potemkin is intentionally self-contained in a single typed Python 3.10+ module with zero external runtime dependencies.

Package Layout

  • skills/potemkin/scripts/potemkin.py — AST/regex scanner, route extractor, diff cheat detector, SARIF 2.1.0 & baseline engine.
  • skills/potemkin/SKILL.md & references/ — Agent Skill instructions, rules.md, and remediation.md.
  • action.yml & Dockerfile — Composite GitHub Action and minimal container entrypoint.
  • website/ — Warm Ivory static documentation, browser Studio, and live proof pages.

CI Self-Audit

Every commit in this repository runs ruff check ., strict mypy, pytest -v, and potemkin . --fail-on any --min-score 100 to verify 100/100 integrity with zero self-findings.
