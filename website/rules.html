Rules Matrix (POT001–POT016)

Filter all 16 deterministic checks by pillar, keyword, or rule ID.

Rule Pillar Severity Detection & Remediation
POT001HOLLOW_UIhigh (-9)Hollow UI event handler
No-op or console-only handler on a UI trigger. Wire it to state mutation or real API calls.
POT002HOLLOW_UImedium (-4)Dead placeholder link (#)
Point href/to at a real route, valid #section-id, or convert to a button.
POT003HOLLOW_UIhigh (-9)Theater submit handler
Simulated delay/toast without persistence. Connect form submission to a real request or Server Action.
POT004FAKE_FALLBACKcritical (-18)Deceptive error fallback returning mock/fake success
Propagate errors or return an explicit non-200 failure instead of returning fake success data.
POT005FAKE_FALLBACKhigh (-9)Silent catch/except swallowing errors
Handle, log with context, or rethrow exceptions explicitly so runtime failures stay visible.
POT006FAKE_FALLBACKcritical (-18)Webhook handler lacks cryptographic signature verification
Verify HMAC/provider signature headers using constant-time comparison before processing payloads.
POT007MOCK_IN_PRODhigh (-9)Mock fixture, placeholder literal, or NotImplemented stub in runtime
Replace sample identifiers, example.com defaults, or non-ABC stubs with real data loaders.
POT008WIRE_GAPhigh (-9)Frontend request calls missing backend route or mismatched HTTP method
Align frontend URL/verb with an actual Express, Next.js, FastAPI, or Flask handler.
POT009WIRE_GAPmedium (-4)Orphan backend route with zero callers or test references
Wire the endpoint into the client/tests or delete stale scaffolded handlers.
POT010WIRE_GAPmedium (-4)Hardcoded localhost URL in runtime code
Read base URLs from environment variables with explicit production configuration.
POT011ENV_TRUTHcritical (-18)Insecure hardcoded fallback for security-sensitive secret
Fail fast at startup if required secret env vars are unset in production.
POT012ENV_TRUTHcritical (-18)Sensitive secret exposed with client-bundle public prefix
Remove NEXT_PUBLIC_, VITE_, or PUBLIC_ prefixes from server secrets immediately.
POT013ENV_TRUTHmedium (-4)Required runtime env var missing from .env.example
Document every non-standard runtime env var in .env.example for clean onboarding.
POT014DIFF_CHEATcritical (-18)Agent reward hacking: skipped/disabled test added in git diff
Fix the broken test or implementation instead of adding .skip, xit, or pytest.mark.skip.
POT015DIFF_CHEAThigh (-9)Type/lint/hook suppression introduced in git diff
Resolve underlying violations rather than slipping @ts-ignore, type: ignore, or --no-verify into diffs.
POT016DIFF_CHEAThigh (-9)Hollowed test assertions in git diff
Restore behavioral assertions instead of deleting checks or asserting trivially in test edits.
