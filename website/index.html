Frequently Asked Questions

What does Potemkin catch that linters and type checkers miss?

Linters validate syntax and formatting. Potemkin inspects architectural completion across 6 pillars: hollow handlers, silent error swallowing, runtime mock data, mismatched frontend-backend routes, insecure secret fallbacks, and git-diff cheating like newly skipped tests.

How does Potemkin compute the 0–100 Integrity Score?

Every scan starts at 100 and deducts 18 points per CRITICAL issue, 9 per HIGH, 4 per MEDIUM, and 1 per LOW. Scores of 90–100 pass as VERIFIED, 70–89 warn as CAUTION, and below 70 trigger POTEMKIN ALERT.

Does Potemkin require LLM API keys or internet access?

No. Potemkin uses zero external runtime dependencies and runs exclusively on the Python 3.10+ standard library, making it deterministic for pre-commit hooks, agent verification loops, and CI workflows.
